1. Scrape

Drag this button to your browser's bookmarks bar.

🦠 Noöscope Scraper
  1. Drag the '🦠 Noöscope Scraper' button to your bookmarks bar.
  2. Navigate to an X (Twitter) post, a user profile, your home timeline, a Bluesky thread, or another supported page.
  3. Click the '🦠 Noöscope Scraper' you just saved.
  4. On X/Twitter, the page scrolls to collect posts — click "Stop" when ready and save the downloaded JSON file. On Bluesky, it jumps you to the importer with the thread URL already filled in.

2. Embed & project

Turn one or more scraped files into a single visualization file, from the terminal:

export OPENAI_API_KEY=sk-...
node scripts/pipeline.mjs your-scrape-1.json your-scrape-2.json -o out.json

Multiple files are embedded together and plotted in one shared map, colored by source. See the repo README for the full pipeline (embedding and projection can also be run as separate steps).

3. Visualize

Open the viewer and drop in the file from step 2 — no server, no account, no database. Just the file.
