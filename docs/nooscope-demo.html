Ingestion schema

Every source — Hacker News front page, a Discord server, or a network of X accounts — is normalized to the same shape before it reaches the constellation. This is what lets one instrument read all three.

{
  "message":   "string",      // raw text
  "author":    "string",      // handle / username
  "timestamp": "ISO8601",
  "parent":    "id | null",   // optional — reply-to
  "children":  "id[]"         // optional — replies
}
